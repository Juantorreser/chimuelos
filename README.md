# chimuelos

Sitio privado de 6 meses — solo para nosotros.

Hecho con React + TypeScript + Vite. Incluye:

- Portada con el nombre **chimuelos**
- Contador de tiempo juntos
- Línea de tiempo de momentos
- Muro de fotos (placeholders)
- Carta para abrir
- Lista de razones
- Cierre romántico

## Desarrollo

```bash
npm install
npm run dev
```

## Personalizar (mockup)

Edita `src/App.tsx`:

- `TOGETHER_SINCE` — fecha de inicio
- `milestones`, `photos`, `reasons` — textos y captions
- Sustituye los placeholders de foto por imágenes reales en `/public`

## Build

```bash
npm run build
```
